## Data types used
- `INTEGER`: ID
- `CHAR(5)`: fixed-length code
- `VARCHAR(30)`: variable-length name
- `SMALLINT`: age
- `DECIMAL(9,2)`: salary
- `DATE`: date
- `TIME`: time
