# Conceptos

- `MAX()` es una función agregada: resume varias filas en un valor.
- Una subconsulta es un `SELECT` utilizado dentro de otra sentencia.
- Una subconsulta anidada permite encadenar varios niveles.
- Una subconsulta correlacionada referencia valores de la fila de la consulta exterior.
- `A` y `B` son alias distintos para referencias a la misma tabla.
- `COUNT(*)` permite calcular cuántas filas cumplen la condición correlacionada.
- TOP-N se obtiene conservando las filas cuyo número de salarios superiores es menor que N.

La prueba se hizo con salarios distintos; el tratamiento de empates no se estudia en este lab.
